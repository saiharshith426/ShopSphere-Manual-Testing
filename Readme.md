# ShopSphere Manual Testing
 
This is my manual testing assignment for the practice shop at https://practicesoftwaretesting.com. I'm new to QA, so I kept the process simple: read the requirements, write scenarios and test cases, run them by hand on the site, and note down what I found.
 
## What's in this folder
 
- `Test-Scenarios.xlsx`: 23 test scenarios
- `Test-Cases.xlsx`: 23 test cases, one sheet per module
- `Bug-Reports.xlsx`: 5 bugs I found
- `Screenshots/`: a screenshot for each bug (BUG-01.png to BUG-05.png)
- `Test-Execution-Report.md`: a short summary of how the testing went
  
## What I tested
 
Login and Registration, Product Search, Shopping Cart, and Checkout and Payment.
 
I skipped Coupon Application because I couldn't find a coupon option on the site, which the assignment allows.
 
## Tested on
 
Browser and OS: Chrome and Ubuntu, November 2026
 
## A note on the bugs
 
All five are in the registration form. I only reported things I actually saw, and I didn't note the list to reach a number.
